When you try to type input with tabs into a program like cat an interupt signal is sent this is because tab and ^I have the same ASCII value.
The TAB key does not result in the same interuption either due to vi having signal handling or ignore signals such as SIGINT. The other explanation is that vi changes the terminal settings disabling the ISIG flag with characters such as the interrupt character no longer being converted to signals.

Signal 40 is a real-time signal. Thus, all three instances of the signals sent from process A are queued while blocked by process B. When process B unblocks the signal, the handler is executed 3 times, once for each instance within the queue.
