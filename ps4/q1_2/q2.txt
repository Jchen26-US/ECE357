2A)
A named pipe can be created using mknod() or mkfifo() system calls as follows:
mknod("/tmp/namedpipe", S_IFIFO | 0600, 0);
Alternataively, the shell commnad mkfifo can be used.
2B)
Namedpipes allow a process to use the open() syscall to access a pipe which is not possible with unnamed pipes. This allows multiple processes to communicate through a common path.
